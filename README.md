# 📚 MERN Stack Online Book Store & Marketplace

A full-stack e-commerce web application built using the MERN stack (MongoDB, Express.js, React.js, Node.js). The platform connects book sellers with buyers, allowing sellers to list books for sale while enabling users to seamlessly browse, search, order books online, and directly communicate with sellers.

---

## ✨ Features

### 🛍️ For Buyers / General Users
- **Browse & Search:** Explore a wide catalog of available books with detailed descriptions, author information, and pricing.
- **Order Placement:** Easily select books and place orders online.
- **Seller Contact System:** Send direct messages/inquiries to sellers for questions regarding book availability, condition, or delivery details.
- **User Authentication:** Secure signup and login functionality.

### 🏪 For Sellers
- **Book Management (CRUD):** Add new books with details, images, category, and price, or update and delete existing listings.
- **Manage Inquiries:** Receive and manage messages/inquiries sent by interested buyers.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, HTML5, CSS3, JavaScript (ES6+), ReactRedux / Rest API's
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose ODM
- **Authentication:** JSON Web Tokens (JWT) / Bcrypt password hashing
